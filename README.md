# Oficina Git — Guia de Comandos

Página educativa em HTML e CSS com exemplos de comandos Git. Material de estudo sobre controle de versão.

## Conteúdo

- `git init`, `git clone` e `git status`
- Preparação de alterações com `git add`
- Histórico com `git commit`
- Sincronização com `git push` e `git pull`
- Comandos adicionais em [outros.html](outros.html)

## Visualizar

Clone ou baixe o repositório e abra [index.html](index.html) no navegador. Não há instalação de dependências nem etapa de build.

## Arquivos

| Arquivo | Conteúdo |
| --- | --- |
| [index.html](index.html) | Guia dos comandos principais |
| [outros.html](outros.html) | Comandos adicionais |
| [styles.css](styles.css) | Estilos da página |

## Contexto

Exercício de aprendizagem de Git e desenvolvimento web básico.
